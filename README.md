# AnimeLIB Desktop

Desktop приложение для просмотра аниме с удобным интерфейсом и современными возможностями воспроизведения видео.

## 🖥️ Описание

AnimeLIB Desktop - это кросс-платформенное настольное приложение на базе Electron, представляющее собой веб-порт сайта animelib.org через WebView с интегрированным кастомным видеоплеером. Приложение предоставляет пользователям доступ к обширной библиотеке аниме с удобной навигацией, качественным воспроизведением видео и дополнительными функциями, специально адаптированными для настольных компьютеров.

## ✨ Основные возможности

- 🌐 **WebView интеграция** - полный доступ к сайту animelib.org через встроенный браузер
- 🎥 **Кастомный видеоплеер** - собственный плеер на базе Shaka Player с расширенными возможностями
- 🚀 **NVIDIA RTX Video Super Resolution** - автоматический AI-апскейлинг видео через драйвер NVIDIA (требует RTX 20xx+, драйвер 531.29+, включённый VSR в настройках NVIDIA)
- 🖼️ **Превью кадров** - YouTube-подобные превью при наведении на прогресс-бар
- 📺 **Поддержка форматов** - HLS (m3u8) и HTTP Progressive Download
- 🎬 **Управление эпизодами** - удобная навигация по сериям с автовоспроизведением
- ⏩ **Автопропуск** - автоматический пропуск опенингов и эндингов
- 💬 **Субтитры** - ASS/SSA через libass (JASSUB), а также SRT/VTT; выбор дорожки, размер, фон/обводка и смещение
- 💡 **Адаптивная подсветка** - адаптивная амбиентная подсветка по краям видео с возможностью отключения
- 🔖 **Кнопка Закладки** - быстрый доступ к закладкам «Смотрю» с любой страницы сайта
- ▶️ **Продолжить просмотр** - кнопка перехода к последней закладке на страницах сайта
- 💬 **Комментарии** - система комментариев к эпизодам с Markdown поддержкой
- ⚙️ **Настройки качества** - автоматический и ручной выбор качества видео
- 🎮 **Горячие клавиши** - полный набор клавиатурных сочетаний для управления
- 📱 **Кастомный Toolbar** - собственная панель управления окном с перетаскиванием
- 🔄 **Обновление по кнопке** - проверка новой версии на GitHub при запуске, загрузка и запуск установщика одним кликом
- 📥 **Менеджер загрузок** - дает возможность скачивать серии для просмотра в оффлайн режиме.

## 🚀 Установка и запуск

### Предварительные требования
- **Node.js**: 18.x или новее
- **npm**: 9.x или новее
- **Git**: для клонирования репозитория

### Установка для разработки

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Fazer000/AnimeLib-Desktop.git
cd AnimeLib-Desktop
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите приложение в режиме разработки:
```bash
npm start
```

### Сборка приложения

#### Для текущей платформы
```bash
npm run package
```

#### Для конкретной платформы
```bash
# Windows
npm run package:win

# macOS
npm run package:mac

# Linux
npm run package:linux
```

Собранные файлы будут находиться в папке `release/build/`.

### Публикация обновления

1. Поднять версию в `package.json` и собрать установщик: `npm run package`
2. Создать релиз на GitHub с тегом вида `v1.7.0`
3. Приложить к релизу файл `AnimeLib-Desktop-Setup-1.7.0.exe` из `release/build/`

Приложение сравнивает `tag_name` последнего релиза со своей версией при запуске
и каждые 6 часов. Если версия новее — в тулбаре появляется зелёная кнопка
обновления: она скачивает установщик во временную папку, запускает его и
закрывает приложение. При ошибке открывается страница релиза в браузере.

## ⚙️ Конфигурация

### Настройки приложения
Настройки хранятся в:
- **Windows**: `%APPDATA%\animelib-desktop\config.json`
- **macOS**: `~/Library/Application Support/animelib-desktop/config.json`
- **Linux**: `~/.config/animelib-desktop/config.json`

### Оффлайн-библиотека
Файлы и каталог хранятся в выбранной директории загрузок (по умолчанию `<userData>/offline`):
- `index.json` - каталог скачанных аниме и серий
- `downloads.json` - незавершённая очередь загрузок
- `<uuid>.bin` - видеофайл прямого источника Animelib
- `<uuid>.ts` + `<uuid>.m3u8` - склеенный поток Kodik и локальный плейлист
- `<uuid>.img` - обложка аниме
- `<uuid>.vtt` / `.ass` / `.srt` - дорожки субтитров

Путь к директории хранится отдельно, в `<userData>/offline-settings.json`, поэтому переживает смену папки.

### Сохраняемые данные
- URL сайта
- Состояние окна (размер, позиция, maximize, fullscreen)
- Прогресс просмотра эпизодов (закладки)
- Локальный прогресс оффлайн-просмотра с отложенной синхронизацией
- Токены авторизации
- Настройки качества видео
- Настройки субтитров (дорожка, размер, обводка, смещение)
- Включенные настройки (автопропуск, автовоспроизведение, адаптивная подсветка)

## 🏗️ Архитектура

### Паттерны проектирования
- **OOP (Manager Pattern)** - вся бизнес-логика вынесена в Manager классы
- **Composition** - компоненты составляются из более мелких компонентов
- **Hooks Pattern** - использование React Hooks для состояния и эффектов
- **IPC Pattern** - связь между main и renderer процессами через IPC

### Менеджеры плеера
- **VideoPlayerController** - главный контроллер плеера
- **ShakaPlayerManager** - управление Shaka Player
- **VideoStateManager** - состояние воспроизведения
- **UIStateManager** - состояние интерфейса
- **KeyboardManager** - обработка горячих клавиш
- **QualityManager** - управление качеством видео
- **SubtitlesManager** - дорожки субтитров, рендеринг ASS и стили
- **AutoplayManager** - автовоспроизведение следующего эпизода
- **SegmentManager** - пропуск опенингов/эндингов
- **ThumbnailManager** - генерация превью кадров
- **BookmarkManager** - управление закладками
- **CommentsManager** - управление комментариями
- **PlayerSelectionManager** - выбор озвучки и плеера
- **SkipManager** - UI для пропуска сегментов
- **OfflineSourceGuard** - слежение за исчезновением локального файла активного источника

### Оффлайн-режим
- **OfflineLibrary** (main) - каталог на диске, сверка с файлами, перенос директории
- **DownloadManager** (main) - очередь с параллельными загрузками, докачкой по Range и восстановлением после перезапуска
- **ParallelDownloader** (main) - загрузка одного файла несколькими соединениями по диапазонам, обходит ограничение скорости CDN на одно соединение
- **HlsDownloader** (main) - посегментная загрузка HLS со склейкой в один файл; используется как запасной путь, когда у источника нет прямой ссылки на файл
- **kodikHelpers** (renderer) - получение прямой ссылки на MP4 из HLS-ссылки Kodik: воспроизведение и загрузка идут напрямую, минуя транcмукс сегментов
- **OfflineStore** (renderer) - зеркало состояния, события удаления файлов, возобновление загрузок
- **OfflineCatalog** (renderer) - сборка Episode[] и Player[] из каталога для оффлайн-режима плеера
- **ProgressStore** (renderer) - локальные отметки позиции просмотра, синхронизируемые с сайтом в обе стороны
- **ViewedStore** (renderer) - локальные отметки просмотренных серий при достижении порога хронометража, отправляются на сайт при появлении связи

Локальные файлы отдаются через собственную схему `animelib-offline://` с поддержкой Range,
зарегистрированную и в сессии окна, и в networking engine Shaka Player.
