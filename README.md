## 🖥️ О приложении

**AnimeLib Desktop** объединяет навигацию по каталогу animelib.org через встроенный WebView и собственный видеоплеер на базе Shaka Player. Приложение подхватывает авторизацию, закладки и прогресс просмотра с сайта, добавляя к ним возможности, которых нет в веб-версии: оффлайн-библиотеку и кастомный плеер.

---

## ✨ Основные возможности

* 🌐 **Интеграция с animelib.org**: Полный доступ к веб-версии сайта, личным спискам и каталогу через WebView.
* 🎥 **Кастомный видеоплеер**:
  * **Форматы**: HLS (m3u8) и HTTP Progressive Download.
  * **Выбор вариантов и озвучек**: Переключение плееров и озвучек, ручной и автоматический выбор качества.
  * **Субтитры**: ASS/SSA через libass (JASSUB), а также SRT/VTT — с выбором дорожки, размером, фоном/обводкой и смещением.
  * **Превью кадров**: YouTube-подобные превью при наведении на прогресс-бар.
  * **Пропуск опенингов и эндингов**: Автоматический или по нажатию, с настраиваемыми интервалами.
  * **Пропуск фрагмента**: Перемотка вперёд на заданный отрезок — длительность настраивается с точностью до 5 секунд.
  * **Эффект подсветки (Ambient Light)**: Динамическая адаптивная подсветка по краям кадра.
  * **Режим «Картинка в картинке» (PiP)** и автовоспроизведение следующего эпизода.
* ⬇️ **Менеджер загрузок**:
  * Скачивание серий для просмотра в оффлайн-режиме, с параллельной загрузкой и докачкой после обрыва.
  * Оффлайн-библиотека с обложками, субтитрами и собственным прогрессом просмотра.
* 💬 **Интерактивные комментарии**:
  * Просмотр и написание комментариев к эпизодам с форматированием и спойлерами.
* 🔖 **Синхронизация закладок**:
  * Быстрый доступ к списку «Смотрю» с любой страницы сайта и кнопка перехода к последней закладке.
  * Прогресс оффлайн-просмотра синхронизируется с сайтом при появлении связи.
* 🪟 **Десктопная оболочка**:
  * Собственная панель управления окном с перетаскиванием, сохранение размера и позиции окна.
  * Проверка новой версии на GitHub с загрузкой и запуском установщика одним кликом.

## 🛠 Технические характеристики

### Требования для запуска приложения
* **ОС**: Windows 10/11, macOS 10.15+, Linux (x64)
* **Минимальное разрешение экрана**: 930×480
* **Интернет-соединение**: требуется для просмотра онлайн; скачанные серии доступны без сети

### Требования для разработки
* **Node.js** 18.x или новее и **npm** 9.x или новее
* **Git** для клонирования репозитория
* Для сборки под конкретную платформу нужна эта же платформа

### Используемый стек
* **Оболочка**: Electron, TypeScript, Webpack
* **UI**: React, Material UI (MUI), Emotion
* **Media Player**: Shaka Player (HLS, адаптивный битрейт), JASSUB (libass) для ASS/SSA
* **Редактор комментариев**: TipTap
* **Хранилище и сеть**: electron-store, Axios, собственная схема `animelib-offline://` с поддержкой Range
* **Архитектура**: разделение main/renderer через IPC, бизнес-логика плеера — в классах-менеджерах

## 🚀 Сборка и установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Fazer000/AnimeLib-Desktop.git
   cd AnimeLib-Desktop
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите приложение в режиме разработки:
   ```bash
   npm start
   ```

4. Соберите установщик для текущей платформы:
   ```bash
   npm run package
   ```
   Готовые файлы появятся в каталоге `release/build/`.

### Вспомогательные команды
```bash
npm run lint        # проверка ESLint
npm run lint:fix    # проверка с автоисправлением
npm run typecheck   # проверка типов без сборки
npm test            # запуск тестов
```

## ⚙️ Конфигурация и авторизация

1. **Базовый URL**: По умолчанию используется `https://animelib.org`. Адрес сайта можно изменить в настройках приложения — например, при смене домена.
2. **Авторизация**: Вход выполняется на самом сайте внутри WebView. Скрипт `renderer/scripts/authExtractor.ts` считывает токен авторизации из `localStorage` страницы и передаёт его приложению для выполнения авторизованных API-запросов — списков, комментариев и прогресса просмотра.
3. **Настройки приложения** хранятся в каталоге пользовательских данных Electron:
   * **Windows**: `%APPDATA%\AnimeLib-Desktop\`
   * **macOS**: `~/Library/Application Support/AnimeLib-Desktop/`
   * **Linux**: `~/.config/AnimeLib-Desktop/`
4. **Оффлайн-библиотека** хранится в выбранной директории загрузок (по умолчанию — внутри каталога пользовательских данных). Путь сохраняется отдельно, поэтому переживает смену папки.
